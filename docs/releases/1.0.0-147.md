# Lorvex 1.0.0 (147)

Released to internal TestFlight on 2026-11-20 from [source commit 0e208c27](https://github.com/boyugou/lorvex/commit/0e208c2727c907ca05813c2c682feb998bead165).

## Returning to work on Mac

Open Today after a meeting. A task you have already started offers Continue
even on a day without time slots. Continue reopens its notes and checklist.
The row shows the first unfinished checklist item and the time until your
next calendar event. A task scheduled for the current time offers Start
when the calendar permits.
The featured task appears once and leads keyboard navigation.

If the next scheduled task conflicts with an appointment, its row stays in
the schedule, names the event and opens task details. During a calendar
appointment, Today waits before bringing work back to the top.

## Validation

English and Simplified Chinese native Mac previews exercised Start,
closing the inspector, reading the first unfinished checklist item, and
using Continue to reopen the task. The narrow Chinese layout was checked
in dark appearance, along with a right-to-left Arabic preview. Local app tests covered returning at the exact end of a
meeting, blocked work, days without time slots, calendar conflicts, stale
actions, and the repeated hour when daylight saving time ends. The full
app suite, build metadata tests, static gates, and localized argument checks
passed.
