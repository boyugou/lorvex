# Lorvex 1.0.0 (152)

Available on internal TestFlight from [source commit f76f9ec3](https://github.com/boyugou/lorvex/commit/f76f9ec3f4bc9c8cd77f8f8bd9f3a7290ac2adf9).

## Your first task

On a new installation, write one task on the welcome screen and choose **Add
to Today**. Today opens with that task on your plan. The title is
saved just as you typed it, including day names or hashtags. You can press
Return in the field to save. Leaving the field blank creates nothing.

To bring a plan from another device, choose **Sync with iCloud** and confirm
on the sync page. Setup closes while the normal sync runs. **Skip** opens the
workspace. An empty Today on iPhone or iPad offers the task field in place
of the empty-day illustration.

## Verification

On an isolated iPhone simulator, a task entered in Welcome appeared on Today
and survived relaunch. A second walkthrough used Skip, added work from empty
Today, relaunched and followed the existing-plan option. The Mac welcome
sheet was rendered in light and dark appearances. Tests checked literal task
titles and the product's logical day on both platforms. With an isolated
database and a simulated CloudKit peer, enabling sync restored the peer's
existing task onto Today and left exactly one stored task. The Debug
simulator host now embeds its own development CloudKit entitlement, so
opening the sync path can query the account even on a signed-out simulator.
The Release host keeps its App Store entitlement configuration.
