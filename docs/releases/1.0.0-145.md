# Lorvex 1.0.0 (145)

Released 2026-11-16 from source commit
[`c4a2a8665e305e106f1f3b94e1ba579099cf2837`](https://github.com/boyugou/lorvex/commit/c4a2a8665e305e106f1f3b94e1ba579099cf2837).

## Delivered behavior

- Daily Review mood and energy use five equal-sized, named choices. Selecting
  the active choice again clears it. Layouts adapt to translated labels and
  large text; unanswered remains distinct from neutral.
- Calendar duplicate display offers Off, Matching details (the conservative
  default), and Same title and time. Matching details checks exact timing and
  event content across distinct, known calendars. Each original source remains
  accessible in event details; owned events, task links, and reminders are
  preserved. Settings apply to Today, Calendar, Review, and calendar search.
- The GitHub download also includes build 144's calendar timing improvements:
  optional end times, preservation of source time zones and floating clocks,
  recurrence across daylight saving changes, and field-specific detail edits.

  watchOS build passed. Both App Store packages passed validation before upload.
