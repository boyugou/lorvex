# Lorvex 1.0.0 (157)

[Current download for Apple silicon Macs](https://github.com/boyugou/lorvex/releases/latest). Requires macOS 26 or later.
Also available on internal TestFlight for iPhone, iPad and Mac. [Build source](https://github.com/boyugou/lorvex/commit/e6174e2d9e2d288584cfbcd36164584cbbb6a7ea).

## Plan a task from its list

Open an active task in Inbox or another list. **When** is now the first property.
Select **Set Date** to choose the day you intend to work on it. **Due** shows
its deadline separately. For example, a task due Friday can be planned for
Thursday and stay in the same list.

On iPhone and iPad, **More** holds **Share**, **Cancel Task** and **Delete
Permanently**. A repeating task still offers a choice of occurrence or series
when cancelled. Permanent deletion asks for confirmation. On a narrow iPad
detail pane, the primary action keeps its title alongside Edit and More icons.

## Verification

Native iPhone 17 Pro and iPad mini simulator tests saved an Inbox task, gave it
a deadline of tomorrow, scheduled it for today and dismissed a deletion
confirmation. Both reopened the task after relaunch. A separate database
readback confirmed its list, status and both dates. The iPad walkthrough also
covered the split layout and the rendered primary action at portrait width.

The Mac inspector was rendered against sample data. A store regression opened
Inbox through the sidebar navigation path, scheduled the selected task, reloaded
its deadline from storage and closed the inspector. Inbox remained selected
with the task in its open rows. The Swift app and core suites, static gates
and localization checks passed.

During one simulator reinstall, ExtensionFoundation reported an invalid bundle
record before the widget entered app code. Apple's widget host retried three
seconds later and received all three widget descriptors and both controls.
The iPad walkthrough then passed on the same installation.

Two Mac sample-data tours stopped while switching between Calendar and Today.
The debugger captured AppKit rejecting a duplicate system search toolbar item.
The exception occurred in a debug preview window. [Build 158](1.0.0-158.md)
changed the search host and verified navigation in the tour and regular window.
