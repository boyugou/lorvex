## Daily Review

Daily Review on Mac and iPhone opens with the date and a place to write.
Wins, blockers, and learnings are available when you want a prompt.
Completed work, habits, and tomorrow's schedule give the entry context.

The open task list includes unfinished work planned for the reviewed day and
work due that day. A task that meets both conditions appears once. You can
choose tomorrow, a specific day, or Someday for an individual task. The bulk
action shows how many tasks will move, including eligible tasks below the
first five. Tasks already planned for a later day retain that later plan
when moving the group to tomorrow. Rescheduling preserves deadlines.

## How to try it

1. Plan a task for today without a deadline. Give a second task both a plan
   and a deadline today. Open Daily Review and find both tasks, once each.
2. Write a line about the day. Move the second task to tomorrow and check
   its plan and deadline in the task details.
3. Undo using Command-Z on Mac or the Undo banner on iPhone. Check that the
   original plan, time block, and any associated reminders return.
